First-time setup without Docker

  1. Install Python 3.10 or newer.
  2. Download or clone this repository.
  3. On Windows, double-click run_windows.bat.
  4. On macOS/Linux, run bash run_unix.sh.
  5. Return here and select Open SafetyPulse.
This index page is a launcher. Browsers cannot directly run the Python application, so the included launcher starts Streamlit locally.
