# Security Policy

## Supported version

The latest commit on `main` is the supported demonstration release.

## Reporting a vulnerability

Do not publish security vulnerabilities in a public issue. Contact the repository owner privately with:

- affected version or commit
- reproduction steps
- potential impact
- suggested mitigation, when available

## Production warning

SafetyPulse v1 is a commercial MVP and demonstration system. Before processing confidential or personal data, deploy authentication, role-based access control, encrypted transport, managed backups, tenant isolation, audit logging, malware scanning for uploads, and a production database such as PostgreSQL.

Never commit passwords, API keys, employee medical information, identity documents, or customer production data to this repository.
